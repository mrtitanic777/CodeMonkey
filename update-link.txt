# Where a copy of CodeMonkey looks for new versions, once a day: the latest release of this
# GitHub repository, read through GitHub's API (its attached installers are the downloads).
# A link to a release file that `npm run release-info` (in desktop/) writes works too, and a Google
# Drive or Dropbox share link ("anyone with the link") works as it is. The first line that is not a
# comment is the link. Every build carries it; Settings > What's new can override it per copy.
https://github.com/mrtitanic777/CodeMonkey
